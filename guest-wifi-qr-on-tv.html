Your guest Wi-Fi code on the venue TV, where visitors can scan it. Open vuthis.com on the display, connect from your phone and prepare the Wi-Fi QR screen for the network you intend to share.

For a café, small hotel, reception or holiday rental, the useful result is simple: guests can find the connection details without asking the same question at the desk or reading a small printed card.

Prepare the guest-network details

Use the network specifically intended for visitors. Check its name and password before preparing the screen, and only display information you are authorised to share with the people in that area.

Keep a test phone available so you can check the displayed code from a realistic viewing distance. A QR code that works on the controller preview still needs to be large and clear on the actual room display.

Connect and prepare the Wi-Fi screen

  1. Open vuthis.com in the TV's usable browser, or on the computer already connected to it.
  2. Connect a phone with the display's QR code. A laptop can use vuthis.com/r and the screen code.
  3. Choose the Wi-Fi QR option and enter the guest-network details in its controls.
  4. Show the result on the TV and scan it with the separate test phone.

Make the purpose clear

Place the screen where arriving visitors can see it, and use wording that explains the code is for guest Wi-Fi. Check the result from the entrance or waiting area rather than only from beside the TV.

If you want visitors to open a web page instead, use the link QR-code display option with that destination. A Wi-Fi code and a website-link code do different jobs; choose the one matching the next step you want guests to take.

The display and controller both need internet access; shared Wi-Fi pairing is not required for their connection. For general guest information, you can also show a welcome message or a PDF information sheet through the same controller.

See QR-code display instructions and [reception welcome screens](/reception-tv-welcome-message.html). Keep the network details current when the venue changes its guest access.
