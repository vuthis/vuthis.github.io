A conference, community event or training venue already has useful information in a document: the running order, speaker programme, room allocation or break times. The display version should make the next decision easy for someone who has just walked into the room.

Prepare a programme people can read at a glance

Create a short PDF with the event title, the relevant times and clear room names. A single day's programme may fit on one page. For a busy event, make separate pages for the morning, afternoon or individual rooms rather than shrinking a long schedule onto one screen.

Keep the most useful information near the top. A visitor looking for the next session needs its name, start time and room before they need a biography or an event description.

Put the agenda PDF on TV

  1. Open vuthis.com in the TV's usable browser, or on the computer already driving it.
  2. Connect the organiser's phone with the display QR code, or use a laptop at vuthis.com/r and enter the screen code.
  3. Choose Document, select the programme PDF and choose Show now.
  4. Select Fit page for the complete agenda, then choose the relevant page with Previous and Next.

For a portrait programme, Fit width can make the text larger, with page controls moving through the document a screenful at a time. For an unattended information screen, a shorter landscape page is often easier to keep readable without manual changes.

Make room changes obvious

When a room or start time changes, update the source document, export the revised PDF and show it from the controller. Give the file a clear version name so the team does not select yesterday's programme.

If people only need one urgent instruction, switch to Text and show that message directly. A short “Afternoon workshop moved to Room B” message can be more useful than the whole programme at that moment. The [reception-message article](reception-tv-welcome-message.html) covers that approach.

Add the details on a visitor's phone

If the full programme is already published online, a displayed QR code can link to it. State what visitors will get before asking them to scan. Keep the screen readable for those who simply need the next session without using a phone.

Check the venue screen before doors open

Use a browser on the TV or its existing connected computer/player. The controlling device and display both need internet access; they do not need shared Wi-Fi pairing. Check the visible programme from where visitors enter and keep the controller available for changes.

For a room-by-room setup, consult the TV and projector device guide. For the event team's final check, use the [shared-screen checklist](meeting-room-screen-checklist.html).
