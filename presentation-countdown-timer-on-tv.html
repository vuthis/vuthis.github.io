A visible timer on the room's screen, with controls on your phone. Set the presentation, exercise or break duration, choose a clear label and show the countdown where the group can see it.

This is useful when you want to control an actual room timer rather than play a fixed timer video. V U This lets the controller set up the timer and use its controls while the screen stays visible to the audience.

Put the timer on TV or a projector

  1. Open vuthis.com in the display browser. For a projector, a browser on its existing connected computer can supply the page.
  2. Connect a phone by scanning the display QR code, or connect a laptop at vuthis.com/r using the screen code.
  3. Choose Timer and prepare the duration and label for the activity.
  4. Show it on the room's screen.
  5. Use the timer controls to pause or restart when the session needs it.

Label the next action

An unexplained countdown can leave people guessing. “Group exercise” explains the activity, while “Back from break” explains what happens at the end. Use a short label that is readable from the back of the room.

Check the smallest text and the time display before the session. Keep the controller with the facilitator so an interrupted exercise or changed break does not require someone to reach the display computer.

Move between an instruction and a timer

For a workshop, first show the PDF instruction page. When the activity begins, choose the timer in the controller and show it. Return to Document when the group needs the next PDF page.

This switches the visible screen content between the instruction and the timer. Use it as a simple facilitation routine rather than assuming both appear together.

Both devices need internet access, and shared Wi-Fi pairing is not required. The controlling phone or laptop does not need its own HDMI connection to the display.

Read the timer controls or follow the broader [PDF-and-timer workshop workflow](/training-workshop-projector.html). Keep the [room-screen checklist](/meeting-room-screen-checklist.html) with the facilitator's notes.
