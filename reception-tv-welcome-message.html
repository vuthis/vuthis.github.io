The welcome message is on the reception screen. Change the name, room or instruction from your phone or laptop. Open vuthis.com on the display, connect and choose the message the arriving guests need to see.

In a hotel, conference venue or office reception, the screen can answer the first question before someone reaches the desk: which room, which floor, where to wait, or what time the session begins. A short, clear message is often more useful than a full presentation.

Put the first message on the reception screen

  1. Open vuthis.com in the display's browser, or on the computer already connected to it.
  2. Scan the screen's QR code from a phone, or enter its connection code at vuthis.com/r on a laptop.
  3. Choose Text and enter the welcome or direction.
  4. Choose Show now, then check it from the entrance or waiting area.

Keep the first screen simple. “Workshop registration — first floor” tells an arriving visitor what to do. An internal schedule, a paragraph of background information and several competing instructions make that task harder.

Set up a useful arrival screen

For a training day, show the event name and room. For a hotel meeting, show the group name you are authorised to display and its location. For an office visitor, use the agreed welcome wording without adding personal information that does not belong in a public area.

Prepare a short message for the likely change as well: a different room, a delayed start or a moved registration desk. Keeping the controller available means you can change the screen when the reception situation changes.

If the information is already laid out as a PDF, choose Document instead. A one-page agenda, floor plan or conference programme can use the PDF display workflow.

Use a QR code when the next step is a link

A display QR code can send visitors to an information page, booking page or feedback form. Prepare the destination first, then use the QR-code display option. Test the code on a separate phone from a realistic viewing position.

Make the reason to scan clear beside the code: “Today's agenda” or “Leave feedback” gives it a purpose. V U This displays the link; the destination page handles the booking, registration or form. See the QR-code-on-TV instructions for that screen type.

Keep the room's existing setup

Use the TV's usable browser or a browser on its connected computer/player. Your controlling laptop does not need a new HDMI connection. Both devices need internet access, and shared Wi-Fi pairing is not required.

For a repeatable daily routine, choose one person to check the opening message, keep the current connection details with the venue team and review the screen when the event changes. For a more detailed programme, use an [event agenda on TV](event-agenda-on-tv.html).

Start with the message visitors need right now. Open vuthis.com on the reception screen and connect from your own device.
